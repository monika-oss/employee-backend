Introduction

What is it?

A comprehensive web-based application designed to manage employee data, streamline HR administrative tasks, and provide dedicated portals for both Admins and Employees.

Core Purpose:

  • Eliminates manual record-keeping.
  • Ensures high data accuracy and security.
  • Facilitates a centralized database for seamless HR operations.

Completed Modules

  • Requirement Analysis & Planning
  • UI/UX Design (HTML, CSS, Bootstrap)
  • Frontend Development (JavaScript)
  • Backend Development (Node.js)
  • Database Design (MySQL)
  • Employee Management Module
  • Role-Based Authentication
  • Testing & Deployment (Vercel)

Technology Stack

Frontend: HTML5, Vanilla CSS, Bootstrap, JavaScript

Backend: Node.js, Express.js

Database: MySQL

Deployment: Vercel (Frontend)

The frontend communicates with the backend via RESTful APIs. Secure Token-based Authentication guarantees safe data transit.

Secure Login System

(Live Preview from Vercel)

Admin Dashboard

  • Centralized Control: View overall company metrics.
  • CRUD Operations: Add, Edit, View, and Delete employee records safely.
  • Responsive Design: Bootstrap ensures it works perfectly on mobile devices.
  • Secure Access: Only accessible to users with the 'Admin' role.

Employee Portal

  • Dedicated Space: A personal portal for every employee.
  • Profile Viewing: Employees can check their job details and salary securely.
  • Restricted View: Cannot see other employees' data or administrative tools.

Backend & Database

Database Tables:

  • users (id, email, password, role)
  • employees (id, user_id, first_name, last_name, phone, department, salary)

Security:

  • Passwords are hashed using bcryptjs.
  • API routes are protected using JWT (JSON Web Tokens).
  • CORS enabled for secure cross-origin requests.
